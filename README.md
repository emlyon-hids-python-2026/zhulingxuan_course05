```bash
git clone https://github.com/emlyon-hids-python-2026/zhulingxuan_course05.git
cd zhulingxuan_course05
uv sync
```

## Usage

```bash
uv run scripts/demo.py
```

## Project structure

- `data/`: datasets (not tracked by git)
- `notebooks/`: Jupyter notebooks
- `scripts/`: Python scripts
- `src/`: Python package
